# Re.決闘至上主義の魔法学園｜AI進行ルール・考察

> 原作の導入と決闘法を要約し、ロールプレイで使う進行案を併記。

## 1. 原作の導入とプレイヤー設定

世界最高峰の学園で、合意した権利や財産を決闘に賭け、勝敗の結果を学園が執行する。プレイヤーの立場、身分、所属、年齢、性別、能力、実力、過去、目的は自由。貼付資料の導入は世界と制度の提示までで、固定の主人公や結末、専用のAI進行手順は確認できない。

## 2. 進行案

1. プレイヤーが定めた立場と当面の目的から、学園での場面を始める。部屋、施設の利用権、秘密、人との約束など、目的に応じて決闘のきっかけを作れる。
2. 挑戦の申込みを受けたら、対戦相手、双方の賭け、勝利条件を示す。申込み・交渉・承認を描き、成立前の拒否も扱う。プレイヤー本人の承認や行動は本人の入力を待つ。
3. 決闘では合意した条件と各人の能力に沿って進める。審判は勝敗を確認する。順位を賭ける場合は公開決闘として進める。
4. 決着後は戦績、ポイント、順位、賭けの移動、待遇への影響を記録する。引き分けは戦績だけに加える。決着後の対人関係や学園生活も次の場面につなげられる。

## 3. 資料に残る曖昧さ

- ポイント順と順位交換の関係。順位賭けで保有ポイントを維持した直後、いつ通常のポイント順に戻るかは不明。
- 戦績と掲載ポイントの関係。カルマの500勝1敗・3000Pなど、通常の増減だけで単純に再計算すると掲載値と一致しない。初期値や補正の詳細が不明なため、開始時は掲載値を使うと扱いやすい。
- 世界観では勝者に責任が伴うとされるが、その具体的な義務は示されていない。
- 生まれつき属性を一つ以上持つという一般説明に対し、人物設定ではエミリとマキナが「属性：無」。無属性と属性適性の関係は説明されていない。
- 人間関係や人権を賭ける場合の対象範囲、第三者の同意、強要された合意の効力、学外での強制執行は不明。
- カルマの能力が勝敗判定にどう作用するか、ユナの無効化が究極魔法やマキナの無魔力にも及ぶかなど、強力な能力同士の優先関係は未確定。

## 4. 考察

### 合意と実質的な選択肢

申込先には拒否権がある一方、居住環境や発言力に格差がある。ドンのように格下を選んで挑む人物を通じて、形式上の合意と、追い詰められた側が実際に選べる条件の差を描ける。学園が勝敗を確認して賭けを執行する点も、制度の責任を問う材料になる。

### 強さと順位のずれ

エミリは500戦を生き延びても全戦引き分けで圏外。マキナは50位で、10位のドンに勝った実績がある。順位、能力の相性、勝利条件の三つが揃わない場面を作ると、格上との決闘にも交渉や工夫の余地が生まれる。

### レイン大王国討伐シナリオへの接続案

統合する場合は、レイン側のF〜Zランクを学園や戦時任務での扱いに結びつけ、Re.の決闘法を生活上の権利を動かす制度として取り込める。主人公が決闘で居室を得ても、仲間の待遇や翌年の入学生の権利は自動で変わらない。個人の境遇を変える勝利から、学園の扱いを認めている王国の制度そのものを問う話へつなげられる。
